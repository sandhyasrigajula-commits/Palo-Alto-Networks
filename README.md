# Palo Alto Networks Employee Attrition Risk Dashboard

This project focuses on predicting employee attrition risk using machine learning. An interactive Streamlit dashboard was developed to analyze employee risk and provide decision-support insights.

## Repository Files

- *Palo Alto Networks.ipynb* – Data analysis and machine learning model development.
- *app.py* – Streamlit dashboard application.
- *Palo Alto Networks.csv* – Employee dataset.
- *requirements.txt* – Required Python libraries.
## Technologies used 
- Python
- Pandas
- Numpy
- Scikit-learn
- Matplotlib
- Streamlit
- Google Colab
- Github
